# 商談AIロープレ

大学キャリアセンター職員との商談を、AIアバター相手に練習できるWebアプリです。
テレアポで取得したアポ背景から商談相手を自動で作り、商談後に「目線・表情」と「会話の内容」を評価します。

## できること

| 機能 | 仕組み | 費用 |
|---|---|---|
| 商談相手の自動作成（アポ背景から） | Gemini API（設定で Claude にも切り替え可） | 無料枠（Claudeは使った分だけ） |
| AI職員との音声での会話 | Gemini API＋ブラウザの音声認識・読み上げ | 無料枠 |
| アバター表示（話すと口が動く） | SVG | 無料 |
| 自分のカメラ映像・目線・表情の計測 | MediaPipe（ブラウザ内で処理。映像は外部に送らない） | 無料 |
| 商談の評価・改善点・回答例 | Gemini API | 無料枠 |
| 練習の履歴 | ブラウザ内に保存 | 無料 |

## 使い方

1. [Google AI Studio](https://aistudio.google.com/apikey) で無料のAPIキーを発行する（有料の Claude も選べます：[Claude Console](https://platform.claude.com/settings/keys)）
2. アプリを開き「設定」でAPIキーと社内の情報（サービス情報・事実・他の選択肢との違いなど）を入力して保存。社内で作った設定ファイルがあれば「ファイルから読み込む」で取り込む
3. 「練習する」でアポ背景を貼り付け → 相手のタイプ・難易度・時間を選んで「シナリオを作成」
4. 「商談を始める」→「商談に入る」。マイクで話して、黙ると自動で送信されます（「〜です」「〜ますか」で言い切ったときは短く、「〜で」「えーと」で止まったときは長めに待ちます。待ち時間は設定で変えられます）。AIが話している途中でも、話し始めればAIは止まります
5. 終わったら「商談を終了して評価」（AIが商談を締めくくった場合は自動で終了）

**ブラウザはパソコンの Google Chrome か Microsoft Edge を使ってください**（音声認識に対応しているため）。イヤホンを使うと、AIの声をマイクが拾いにくくなり、話し始めたときにAIを止める動きが安定します。

## 手元で動かす

```bash
cd sales-roleplay
npm install
npm run dev
```

## カスタマイズの場所

### 社内の情報 → アプリの「設定」画面
このリポジトリは公開されるため、**社内の情報はコードに書かず、アプリの「設定」画面に入力します**。
入力内容はブラウザの中にだけ保存され、「ファイルに書き出す」で作ったファイルを社内で直接渡せば、ほかの人も同じ設定で練習できます。

| 設定画面の欄 | 使われ方 |
|---|---|
| サービス情報 | AIが質問を考える材料 |
| サービスの事実 | 営業の発言が事実と合っているかの評価 |
| 他の選択肢との違い | 違いを相手の悩みに結びつけて伝えられたかの評価 |
| 商談相手の立場 / 大学の今の取り組み・予算の考え方 | 職員役AIの設定 |
| 実際の商談で出てきた悩み | 「電話では言っていない悩み」を作るときに優先 |
| AIが必ず聞く質問 | 毎回必ず聞かれる質問と、その続き |
| 商談のゴール | クロージングの評価 |
| アポ背景のサンプル | 商談準備画面のサンプルボタン |

### 仕組み・評価のルール → `src/config/`
どの会社にも当てはまる一般的な内容だけを置きます。

| 変えたいこと | ファイル |
|---|---|
| 評価項目・重み・見るポイント | `src/config/rubric.ts` の `RUBRIC` |
| 目線・表情の点数の付け方 | `src/config/rubric.ts` の `FACE_SCORING` |
| 目線・笑顔の判定の厳しさ | `src/config/settings.ts` の `FACE_THRESHOLDS` |
| 相手の性格タイプ・難易度、電話では言っていない悩みの数 | `src/config/personas.ts` |
| サービス外で聞いてくる話題 | `src/config/knowledge.ts` の `OFF_TOPIC_THEMES` |
| 設定画面の入力欄（説明文・入力例） | `src/config/knowledge.ts` の `KNOWLEDGE_FIELDS` |
| AIへの指示文（話し方・評価の厳しさ） | `src/config/prompts.ts` |
| 商談時間の上限、読み上げ速度、会話用の Gemini モデル | `src/config/settings.ts` の `APP_DEFAULTS` |
| 話し終わりの待ち時間（短め・ふつう・長め） | `src/config/settings.ts` の `PAUSE_PRESETS` |
| 「言い切った」とみなす語尾 | `src/lib/speech.ts` の `SENTENCE_FINISHED` |
| アバターの見た目 | `src/components/Avatar.tsx` |
| 使えるClaudeのモデル | `src/config/settings.ts` の `CLAUDE_MODELS` |
| AIとの通信（ほかのAIを足す） | `src/lib/llm.ts` |

## 注意点

- **料金**：初期設定の Gemini は無料枠で使えます（1分・1日あたりの回数に上限あり）。Claude を選ぶと使った分だけ料金がかかります。
- **データの扱い**：Gemini の無料枠では、設定画面の内容・商談の会話・評価が Google のサービス改善に使われ、人が読むこともあります。社外秘の情報、実在の大学名・人名は入れないでください。音声認識は、Chrome なら Google、Edge なら Microsoft のサーバーで声を文字にしています。カメラの映像は外部に送りません。Claude API に送った内容は、初期設定ではAIの学習に使われません。
- **目線・表情は参考値**：Webカメラの位置・照明・メガネで判定がぶれます。
- **データの保存先**：設定と履歴は、使っているブラウザの中だけに保存されます。別のPCやブラウザとは共有されません。
