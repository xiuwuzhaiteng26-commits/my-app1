# バイクツーリング スポットナビ

条件を選ぶだけで、あなたにぴったりのバイクツーリングスポットを提案するWebアプリです。

## 主な機能

- **簡単診断**: 走行レベル・見たい景色・季節・日程を選ぶと、条件に合うスポットを上位3件おすすめ表示
- **スポット一覧**: 全国18箇所のツーリングスポットを地域・キーワードで検索・絞り込み
- **詳細表示**: 見どころやツーリングTipsなどをモーダルで確認

## 開発

```bash
npm install
npm run dev      # 開発サーバー起動
npm run build    # 本番ビルド
npm run lint     # Lint実行
```

## 技術スタック

- React + TypeScript
- Vite
